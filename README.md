# C23 Solar

Marketing site for C23 Solar. Static — no build step: open `index.html` or serve the folder.

- `index.html` — content
- `styles.css` — design
- `main.js` — scroll-driven sky, estimator, enquiry form

Before launch: set the enquiries address in `data-email` on the form in `index.html`, and review the draft copy.

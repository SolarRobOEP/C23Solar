# C23 Solar

Marketing site for C23 Solar. Static — no build step: open `index.html` or serve the folder.

- `index.html` — content
- `styles.css` — design
- `main.js` — scroll-driven sky, estimator, enquiry form

- `assets/` — logo SVGs converted from the brand EPS artwork

Before launch: confirm the enquiries address (`data-email` on the form in `index.html`) and review the draft copy.
